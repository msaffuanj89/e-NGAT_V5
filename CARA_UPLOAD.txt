Untuk repository baharu e-NGAT_V6:
1. Cipta repository public bernama e-NGAT_V6.
2. Upload SEMUA isi ZIP ini terus ke root repository e-NGAT_V6.
3. Pastikan Settings > Pages menggunakan branch main dan folder /(root).
4. Ikut FIREBASE_SETUP.txt untuk publish Firestore Rules, cipta akaun admin
   dan tambah authorized domain GitHub Pages.
5. Tunggu deployment selesai, kemudian buka:
   https://msaffuanj89.github.io/e-NGAT_V6/
6. Buat hard refresh browser (Ctrl+Shift+R atau Cmd+Shift+R).
